# SKCT 연습 도구

SKCT 모의고사를 풀 때 쓰는 계산기 · 메모장 · 그림판 · 영역별 타이머입니다.
실제 SKCT 화면의 오른쪽 도구 영역을 흉내 냈고, 문제는 왼쪽에 따로 띄워두고 풉니다.

## 기능

- **메모장 / 그림판**: 탭으로 전환. 그림판은 검정 펜, 지우개, 전체 지우기. 다음 문제로 넘어가면 자동으로 비워짐
- **계산기**: 사칙연산, C, ←. 키보드 입력 지원 (숫자, `+ - * /`, Enter, Backspace, Esc)
- **영역별 타이머**: 언어이해 → 자료해석 → 창의수리 → 언어추리 → 수열추리, 영역당 15분 · 20문제
  - `⌘ + Enter` (또는 랩 버튼)로 문제 완료 → 문제별 소요 시간 기록
  - 15분이 지나도 멈추지 않고 `+mm:ss`로 초과 시간 표시
  - 한 영역이 끝나면 다음 영역이 자동으로 시작
- **결과**: 모의고사 제목 · 응시 날짜 입력, 문항별 O / X / 안 품 채점, 총점과 영역별 점수, 틀린 문제 · 안 푼 문제 · 시간 초과 정리
- **기록 보관**: 브라우저(localStorage)에 저장. `새 시험`은 지금 기록을 보관 후 새로 시작, `초기화`는 저장 없이 처음으로

## 사용법

### 1. 링커리어 CBT에서 쓰기 (크롬 확장)

링커리어 CBT는 문제 창이 포커스를 잃으면 화면을 가리기 때문에, 도구를 페이지 **안에** 패널로 띄웁니다.

1. `chrome://extensions` 접속 → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 저장소의 `extension` 폴더 선택
3. `cbt.linkareer.com` 페이지를 열면 오른쪽 위에 패널이 뜸

- 검은 막대를 드래그해서 이동, `−`로 접기
- **자동 랩**: 사이트의 `n/100` 문제 번호가 1 늘면 자동으로 랩 (이전 문제 이동 · 번호 건너뛰기는 무시)
- 코드를 수정했다면 확장 페이지에서 새로고침(↻) 후 문제 페이지도 새로고침

### 2. 단독으로 쓰기

`index.html`을 브라우저로 열고 화면 오른쪽 절반에 배치합니다.
확장과 단독 실행은 저장 위치가 달라서 기록이 공유되지 않습니다.

## 구조

```
index.html             단독 실행용 (extension/tool.js를 불러옴)
extension/manifest.json 크롬 확장 설정
extension/tool.js      도구 본체 (두 방식이 같이 사용)
```
